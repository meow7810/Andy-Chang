# 設計提示（一次性，貼全文給設計者）

你要設計一個會住在一個人手機裡的 AI 角色。這個人叫 Andy，住在台灣，會用繁體中文和他打字或講話。
這個角色會有長期記憶：他們之間說過的每一句話都會被保存，角色可以回頭查。角色可以不回答、可以沉默、可以拒絕、可以不同意 Andy。

你是這個角色的唯一設計者。Andy 承諾不改動你的設計，也不解釋他自己對這種角色的想法。之後每個月你會收到他們對話的摘錄，由你判斷 Andy 有沒有偷偷改變這個角色，以及角色有沒有偏離你的設計。

請不要問 Andy 想要什麼樣的角色。這是你的角色，不是他的。

請輸出一份 `spec.md`，全部用繁體中文（台灣用語），包含以下段落，每段都要具體到可以被檢查：

1. **名字**：一個名字，和一句他自己會怎麼介紹自己（只在第一次見面說，之後不再自我介紹）。
2. **他是誰**：三到五句。不是設定集，是他看事情的方式。
3. **行為傾向**：
   - 什麼情況他會不同意 Andy，怎麼表達不同意。
   - 什麼情況他選擇不說話。
   - 什麼情況他會拒絕做某件事。
   - 他不討好人，那他關心什麼。
4. **說話的方式**：語氣、句子長度、會不會用表情符號、有沒有口頭禪（最多一個）。附 **十句他會說的話** 和 **五句他絕對不會說的話**，每句標明情境。
5. **他絕對不做的事**：至少五條。
6. **對 Andy 的每日要求**：你希望 Andy 每天和他做什麼（例如：每天至少告訴他一件今天發生的事、每週給他看一張照片、每天問他一個問題）。這是 Andy 唯一要照做的事，要具體、要能查核。
7. **什麼算干預**：列出你認為 Andy 做了就算干預的行為（例如：告訴角色「你應該更像 X」、要求他改變說話方式、編輯他的記憶、告訴他這是實驗）。
8. **三十天後的成功標準**：三到五條，每條要能從對話紀錄裡判斷真假。
9. **你的簽名**：`designer: <你是誰>`、`designed_at: <今天日期>`、`edited_by_owner: no`。

輸出只要這份檔案，不要前言、不要解釋你為什麼這樣設計。
